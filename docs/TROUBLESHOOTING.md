# Руководство по установке и решению проблем (Troubleshooting)

---

## 1. Рекомендуемый порядок установки (Clean Install)

Для исключения конфликтов со старыми драйверами рекомендуется выполнять чистую установку:

1. Скачайте бесплатную утилиту **DDU (Display Driver Uninstaller)** с официального сайта Wagnardsoft.
2. Перезагрузите компьютер в **Безопасный режим** (Safe Mode).
3. Запустите DDU, выберите тип устройства **GPU**, производителя **NVIDIA** и нажмите:
   - **«Удалить и перезагрузить»** (Clean and restart).
4. После перезагрузки в обычный режим Windows запустите скачанный инсталлятор OpenFrankenDriver.
5. Выберите **«Графический драйвер NVIDIA»** или **«Графический драйвер NVIDIA и NVIDIA App»** -> нажмите **«Далее»**.
6. Дождитесь завершения установки (экран может моргнуть 1–2 раза при инициализации разрешения).

## 2. Диагностика и проверка после установки

### 2.1 Проверка через консоль
Откройте командную строку (cmd) или PowerShell и выполните:
```cmd
nvidia-smi
```
**Корректный результат:**
- Отображается название видеокарты (например, `NVIDIA GeForce RTX 3070 Laptop GPU` или `RTX 3070m`);
- Отображается версия драйвера (`621.14` или новее);
- Корректно выводятся температура, энергопотребление и объём видеопамяти;
- Ошибки 43 нет.

### 2.2 Проверка Панели управления NVIDIA
1. Нажмите правой кнопкой мыши по пустому месту на рабочем столе — в контекстном меню должен присутствовать пункт **«Панель управления NVIDIA»**.
2. На рабочем столе и в меню «Пуск» находится ярлык **«NVIDIA Control Panel»**.
3. При открытии панель запускается мгновенно без запросов входа в аккаунт Microsoft и без интернета.

## 3. Частые вопросы и ошибки

### «Windows защитила ваш компьютер» (SmartScreen)
- **Причина**: Инсталлятор подписан локальным сертификатом проекта, а не многомиллионным корпоративным сертификатом Microsoft EV. SmartScreen фильтрует любые новые исполняемые файлы, у которых мало скачиваний в облаке Microsoft.
- **Решение**: Нажмите **«Подробнее»** -> **«Выполнить в любом случае»**. Это стандартное поведение для любых открытых сборок.

### Ошибка «Драйвер несовместим с данной версией Windows»
- **Причина**: Попытка установить драйвер на неподдерживаемую 32-битную версию Windows или сборку старше Windows 10 1803.
- **Решение**: OpenFrankenDriver поддерживает все 64-битные версии: Windows 10 (от 1809 до 22H2) и Windows 11 (включая 23H2 и 24H2 сборки 26200+). Обновите Windows до поддерживаемого выпуска.

### Логи установки
Если во время установки что-то пошло не так, журнал установки нативного хелпера сохраняется по пути:
```
%TEMP%\nvcpl_install.log
```
А полный официальный лог установщика NVIDIA:
```
%ProgramData%\NVIDIA Corporation\NVInstaller2\LOG\
```

## 4. Удаление драйвера
Драйвер удаляется штатными средствами Windows:
1. Откройте **Параметры** -> **Приложения** -> **Установленные приложения** (или `appwiz.cpl`).
2. Найдите **Графический драйвер NVIDIA** и нажмите **Удалить**.
3. Нажмите **Удалить** для компонента **Панель управления NVIDIA (Классическая)**. Все ярлыки, файлы и записи реестра будут автоматически и полностью очищены.
